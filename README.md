# ORIE 5135 — Exam Scheduling ILP

Solves an exam scheduling problem using three ILP formulations (F1, F2, F3) implemented with Gurobi and Python.

---

## Requirements

- Python 3.9+
- [Gurobi](https://www.gurobi.com/) 12.x with a valid license
- Python packages: `gurobipy`, `networkx`

Install the packages:

```bash
pip install "gurobipy==12.*" networkx
```

## How to Run

### Step 1 — Solve all instances

```bash
python3 solve.py
```

This runs:
- **Dataset 1** (10 instances, F1 + F2 + F3, 120-second time limit per instance)
- **Dataset 2** (9 instances, F1 + F2 only, 600-second time limit per instance)

Results are saved to `results_dataset1.json` and `results_dataset2.json`.

> **Note:** Dataset 1 takes roughly 20–30 minutes total. Dataset 2 can take up to 2 hours in the worst case due to the 600-second limit per instance.

### Step 2 — Print summary tables

```bash
python3 print_results.py
```

Prints two ASCII tables showing LP relaxation values, objective values, B&B node counts, solve times, and optimality status for each instance and formulation.

---

## Formulations

| Name | Description |
|------|-------------|
| **F1** | Natural ILP — binary `x[i,j]` (exam → slot) and `y[j]` (slot used), with pairwise edge conflict constraints |
| **F2** | Clique-strengthened — replaces pairwise constraints with maximal-clique constraints for a tighter LP relaxation |
| **F3** | Extended set-partitioning — one binary variable per feasible grouping (independent set with proctor budget satisfied); only run on Dataset 1 |

---

## Instance Format

Each `instance_XX.json` file contains:

```json
{
  "m": 35,       // number of exams
  "n": 20,       // number of available slots
  "R": 100,      // proctor budget per slot
  "r": [...],    // list of proctor requirements per exam (length m)
  "edges": [...] // list of [i, j] conflict pairs (1-indexed)
}
```

---

## Output Format

`results_dataset1.json` and `results_dataset2.json` store results keyed by instance name. Each formulation entry includes:

| Field | Description |
|-------|-------------|
| `lp_relaxation` | Optimal LP relaxation value |
| `obj_val` | Best integer objective found |
| `obj_bound` | Best dual bound at termination |
| `node_count` | Total B&B nodes explored |
| `solve_time_s` | Wall-clock solve time in seconds |
| `optimal` | `true` if solved to optimality, `false` if time limit hit |
